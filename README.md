# Git Release Master

Helps to collect releases

## Features

- Создание релизных веток
- Управление коммитами
- Настройка префиксов релизов

## Requirements

- Git
- VS Code 1.125.0+

## Extension Settings

- `gitreleasemaster.releasePrefix`: Prefix used to filter release branches
- `gitreleasemaster.theme`: UI theme (dark/light)
- `gitreleasemaster.language`: UI language (ru/en)
