## План: Табы в «Коммитах для релиза» — ручное добавление + «Создать шаблон»

### Общая структура
**`unstaged.tsx`** (левая панель) — под заголовком «Коммиты для релиза» и `ControlMenu` (он режимозависимый, остаётся общим для обоих табов) добавляются MUI `Tabs` (стили — адаптивные текстовые цвета, как в Settings, иначе в тёмной теме primary #212121 невидим):
- **Таб 1 «Ручное добавление релиза»** — существующий функционал: список полей коммитов + кнопка «Добавить коммит» (переносится без изменений).
- **Таб 2 «Создать шаблон»** — новый компонент.

### Новый компонент `TemplateTab`
**Новые файлы** (конвенция проекта — отдельная папка):
- `commits/unstaged/template-tab/template-tab.tsx`
- `commits/unstaged/template-tab/index.tsx` (barrel)

UI: 
1. `TextField` «Разделитель» (size small, placeholder `,`);
2. `TextField` «Текст» (multiline, minRows 4);
3. `FormControlLabel` + `Checkbox` «trim»;
4. Внизу — превью результата (List dense: номер + значение моноширинно), обновляется на лету;
5. Кнопка «Добавить» (disabled при пустом результате).

Логика (`useMemo`): 
- результат = `text.split(separator)`;
- при активном trim — `.trim()` каждого элемента;
- пустой разделитель → результат `[]` (guard от `"".split("")` побуквенно);
- пустые (после trim) строки — отфильтрованы и из превью, и из добавления.

Кнопка «Добавить» → `addMany(result)`; после добавления — очистить поле «Текст» и переключить на таб 1 (пользователь сразу видит добавленные строки).

### Проброс в форму
- `UnstagedCommitsListProps` += `addMany: (values: string[]) => void`.
- **`commits.tsx`**: 
  ```ts
  const handleAddMany = (values: string[]) => append(...values.map(v => ({ value: v })));
  ```
  и `addMany={handleAddMany}` в `<UnstagedCommitsList>`. Добавление идёт в тот же `useFieldArray` — дальше «Добавить/Применить» работают как обычно.

### Принятые по умолчанию (мелочи, не указанные в ТЗ)
- trim-чекбокс по умолчанию выключен;
- пустые элементы после разбиения не добавляются;
- после «Добавить» — сброс текста и возврат на таб 1.

### Сборка
`npm run build-webview` (хост не меняется) + Reload Window.
