## План: JSON-редактор текстом + фикс темы Tabs

### Задача 1 — JSON-таб как текстовый редактор с применением
**`webview-ui/src/screens/Settings/Settings.tsx`** — `JsonTab` переписать:
- Убрать `ReactJson` (@microlink/react-json-view) → многострочный `TextField` (моноширинный, `minRows=10/maxRows=24`, `spellCheck=false`), текст = `JSON.stringify(settings, null, 2)`.
- `parseSettings(text)`: JSON.parse + валидация формы (объект; `releasePrefix` — строка; `theme` ∈ dark/light; `language` ∈ ru/en) → понятные сообщения об ошибках по-русски.
- На каждый ввод: текст обновляется всегда; если JSON валиден и отличается от последнего применённого → `updateSettings(полный объект)` (автосохранение, как раньше). Невалиден → красный `error` + `helperText` с причиной, ничего не применяется.
- Защита от эха: `lastAppliedRef` хранит каноническое значение (`canon()` — stringify с фиксированным порядком ключей); `useEffect` на `settings` перезаписывает текст только при РЕАЛЬНОМ внешнем изменении (General-таб / конфиг VS Code), а не на эхо собственной правки — курсор не прыгает, порядок ключей хоста не ломает сравнение.
- Проп `themeMode` больше не нужен → убрать из `JsonTabProps` и `SettingsScreenProps` и из вызова в `ScreenRouter.tsx`.
- Заодно `npm uninstall @microlink/react-json-view` (больше нигде не используется — бандл похудеет).

### Задача 2 — Tabs не меняют тему
Причина: активный таб и индикатор красятся в `primary` = **#212121** — в тёмной теме почти невидимы. Фикс — адаптивные текстовые цвета:
```tsx
<Tabs sx={{
  "& .MuiTab-root": { color: "text.secondary" },
  "& .MuiTab-root.Mui-selected": { color: "text.primary" },
  "& .MuiTabs-indicator": { backgroundColor: "text.primary" },
}}>
```
Работает в обеих темах (светлый текст в dark, тёмный в light).
