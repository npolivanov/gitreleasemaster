### Шаг 2. Кнопка в списке веток на Home
`webview-ui/src/screens/Home/index.tsx`, компонент `BranchRow`:
- добавить `secondaryAction={<BranchLogButton branch={branch.name} />}` к `ListItem` — иконка часов справа в каждой строке;
- импорт из `../../features/branch-log`;
- клик открывает popup с логом именно этой ветки (первые 20 коммитов, «Загрузить ещё» по 20, крестик закрывает) — поведение уже реализовано, переиспользуется как есть.

### Шаг 3. Сборка
`npm run build-webview` (хост не меняется) + напоминание Reload Window.
