## План: Экран релиза не должен сбрасываться при переключении вкладок

### Причина
Когда ты уходишь со вкладки расширения (например, в Source Control резолвить конфликты), VS Code **выгружает содержимое webview**. При возврате webview перезагружается с нуля: React-приложение стартует заново, Zustand-store инициализируется дефолтным `view: "home"` → открывается главный экран, wizard и статусы применения теряются.

### Фикс — одна опция панели
**Файл:** `src/extension.ts`, опции `vscode.window.createWebviewPanel`:

```ts
{
  enableScripts: true,
  retainContextWhenHidden: true,   // ← добавить
  localResourceRoots: [...],
}
```

`retainContextWhenHidden: true` приказывает VS Code **не уничтожать** webview при скрытии вкладки: JS-контекст, DOM и всё состояние (шаг wizard'а, форма, статусы cherry-pick, конфликт-алерт) сохраняются живыми. При возврате на вкладку — всё на месте. Платой является удержание памяти на время скрытия — для панели инструмента приемлемо (стандартная практика для таких расширений).

Не покрывается (и не требуется по запросу): полное закрытие панели или перезапуск VS Code — тогда wizard стартует с главного экрана, это ожидаемое поведение.

### Сборка
- `npm run compile` (меняется только host-часть).
- Напомнить про Reload Window.
